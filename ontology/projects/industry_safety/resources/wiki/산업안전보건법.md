| 상시근로자 | 사업장에 상시 사용하는 근로자 (건설공사는 공사금액 기준) | 제3조 |

| 도급인 | 물건의 제조·건설·수리 또는 서비스 제공 업무를 도급하는 사업주 | 제2조제7호 |

| 산업재해 | 근로자가 업무로 인하여 사망·부상하거나 질병에 걸리는 것 | 제2조제1호 |
| 중대재해 | 사망 등 재해 정도가 심하거나 다수의 재해자가 발생한 산업재해 | 제2조제2호 |

## 2. 사업주 의무 조항 (SHACL 검증 대상)

주체 = 사업주·도급인이고 SHACL 가능성 = 가능 또는 부분인 항목만 수록.

| 단위 | 의무 내용 | 조건/기준 | SHACL 가능성 |
|---|---|---|---|
| 제17조(안전관리자) | 사업장에 안전관리자를 두어야 함 | 사업 종류·상시근로자 수 → 대통령령 위임 | 부분 |
| 제18조(보건관리자) | 사업장에 보건관리자를 두어야 함 | 사업 종류·상시근로자 수 → 대통령령 위임 | 부분 |
| 제24조(산업안전보건위원회) | 산업안전보건위원회를 구성·운영하고 회의록을 작성·보존 | 상시근로자 수 → 대통령령 위임 | 부분 |
| 제29조(안전보건교육) | 소속 근로자에게 정기적으로 안전보건교육을 실시 | 교육 시간·내용·주기 → 고용노동부령 위임 (비사무직 분기 6h / 사무직 3h) | 부분 |
| 제32조(직무교육) | 안전관리자·보건관리자 등에게 직무 관련 안전보건교육 이수 | 교육 시간·내용 → 고용노동부령 위임 | 부분 |
| 제36조(위험성평가) | 유해·위험 요인 평가 실시, 결과 기록·보존 | 방법·절차·시기 → 고용노동부장관 고시 | 부분 |
| 제57조(산업재해 기록) | 산업재해 발생 원인 등을 기록·보존 | 기록 항목·보존 기간 → 고용노동부령 | 부분 |
| 제93조(안전검사) | 안전검사대상기계등에 대해 안전검사를 받아야 함 | 검사 주기 → 고용노동부령 위임 (기계 종류별 상이) | 부분 |
| 제98조(자율안전검사) | 자율안전검사 결과를 기록·보존 | 자율검사프로그램 유효기간 2년 (본문 명시) | 가능 |
| 제107조(유해인자 허용기준) | 유해인자 노출 농도를 허용기준 이하로 유지 | 허용기준 → 고용노동부령 위임 | 부분 |
| 제125조(작업환경측정) | 유해인자 있는 작업장에 작업환경측정 실시 및 기록·보존 | 대상·주기 → 고용노동부령 위임 (6개월 1회) | 부분 |
| 제128조의2(휴게시설) | 근로자가 이용할 휴게시설을 갖추어야 함 | 기준 사업장 범위·설치기준 → 대통령령 및 고용노동부령 | 부분 |
| 제129조(일반건강진단) | 상시 사용 근로자에게 일반건강진단을 실시 | 주기·항목 → 고용노동부령 위임 | 부분 |
| 제130조(특수·배치전·수시건강진단) | 유해인자 노출 업무 종사 근로자에게 특수건강진단 실시 | 대상 유해인자·주기 → 고용노동부령 위임 | 부분 |
| 제139조(근로시간 제한) | 유해위험작업 종사 근로자에게 1일 6시간, 1주 34시간 초과 근로 금지 | 1일 6시간 / 1주 34시간 (본문 명시) | 가능 |
| 제164조(서류 보존) | 안전관리자 선임 서류, 산업재해 기록, 작업환경측정 서류, 건강진단 서류 등을 3년 보존 | 3년 (2호 회의록은 2년) (본문 명시) | 가능 |

## 4. 관계

주체 → 동사 → 객체

- 사업주 → 선임하다 → 안전관리자
- 사업주 → 선임하다 → 보건관리자
- 사업주 → 선임하다 → 안전보건관리책임자
- 사업주 → 고용하다 → 상시근로자
- 사업주 → 소유하다 → 사업장
- 사업주 → 실시하다 → 안전보건교육
- 사업주 → 실시하다 → 위험성평가
- 사업주 → 실시하다 → 작업환경측정
- 사업주 → 실시하다 → 건강진단
- 사업주 → 수검하다 → 안전검사
- 사업주 → 기록·보존하다 → 위험성평가기록
- 사업주 → 기록·보존하다 → 작업환경측정기록
- 사업주 → 기록·보존하다 → 건강진단기록
- 사업주 → 기록·보존하다 → 산업재해기록
- 사업주 → 도급하다 → 수급인
- 사업장 → 포함하다 → 작업장
- 작업장 → 포함하다 → 유해인자
- 작업장 → 보유하다 → 안전검사대상기계등
- 안전보건관리책임자 → 지휘·감독 → 안전관리자
- 안전보건관리책임자 → 지휘·감독 → 보건관리자
- 도급인 → 도급하다 → 수급인
- 도급인 → 실시하다 → 작업환경측정 (도급인 사업장 내 관계수급인 작업 시)

## 5. 검증 불가 조항

주체 = 사업주이지만 SHACL 불가로 분류된 항목.

| 단위 | 이유 |
|---|---|
| 제5조(사업주 등의 의무) | 안전·보건 기준 이행 의무가 포괄적·선언적 — 구체적 정량 기준 없음 |
| 제10조(산업재해 발생건수 공표) | 공표 여부는 행정처분 단계 — 사전 RDB 데이터로 확인 불가 |
| 제15조(안전보건관리책임자) | 역할 적절성·실질적 총괄 여부는 주관적 판단 필요 |
| 제16조(관리감독자) | 직위 지정은 가능하나 산업안전보건 업무 수행 적절성은 주관적 |
| 제20조(안전관리자 등의 지도·조언) | 지도·조언 이행 여부는 현장 확인 필요 |
| 제23조(명예산업안전감독관) | 위촉 여부는 행정기관 처분 — 사업주 단독 의무 아님 |
| 제25조(안전보건관리규정 작성) | 작성 여부는 부분 가능하나 내용 적절성은 주관적 |
| 제37조(안전보건표지 설치) | 설치 여부·위치 적절성은 현장 실사 필요 |
| 제38조(안전조치) | 위험 요소별 조치는 현장 상황 의존 |
| 제39조(보건조치) | 위험 요소별 조치는 현장 상황 의존 |
| 제41조(고객폭언 등 건강장해 예방) | 예방조치 적절성은 현장 상황·주관적 판단 |
| 제42조(유해위험방지계획서 제출) | 제출 여부는 부분 가능하나 내용 적절성은 심사기관 판단 |
| 제44조(공정안전보고서 작성·제출) | 유해·위험 설비 보유 여부 확인 가능하나 보고서 내용 적절성은 외부 심사 |
| 제47조(안전보건진단) | 진단 지시 여부는 행정 명령 의존 |
| 제51조(사업주의 작업중지) | 급박한 위험 판단은 현장 상황 의존 |
| 제52조(근로자의 작업중지) | 근로자 요청에 대한 처리는 현장 상황 의존 |
| 제54조(중대재해 발생 시 조치) | 발생 후 즉시 조치는 사후적·현장 상황 의존 |
| 제58조(유해한 작업의 도급금지) | 도급 계약 내용 확인 가능하나 작업 유해성 판단은 전문가 필요 |
| 제61조(적격 수급인 선정) | 적격성 판단은 주관적 |
| 제62조(안전보건총괄책임자) | 선임 여부는 부분 가능하나 역할 수행 적절성은 주관적 |
| 제63조(도급인의 안전·보건조치) | 현장 합동 조치 여부는 실사 필요 |
| 제64조(도급에 따른 산업재해 예방조치) | 협의체 구성·운영 여부는 부분 가능하나 실질 운영은 주관적 |
| 제65조(도급인의 안전·보건 정보 제공) | 정보 제공 여부 및 적절성은 주관적 |
